# Bootcamp Lab task launcher

This launcher lives at the root of the web exercises. Start PHP's local server from this folder:

```bash
cd ~/Epitech-projects/web
php -S 127.0.0.1:8000
```

Open `http://127.0.0.1:8000/` in a browser. Use **Open task** to launch existing HTML/PHP exercises or the interactive task demos. The Day 01 shell playground and SQL bonus runner use sample data or temporary copies so they do not modify the original exercise files or database.

Day 03 is currently empty in this project, so it appears as a note in the launcher. Days 04–05 contain the portfolio project rather than task folders.
